# Практическая работа №2

## Пять методов класса

В класс добавлены пять методов экземпляра, переносящие правила поведения объекта:

| Метод | Назначение |
|-------|------------|
| `TakeDamage(int damage)` | Уменьшает здоровье; отклоняет неположительный урон через ранний `return;` и не опускает здоровье ниже нуля |
| `Heal(int amount)` | Увеличивает здоровье; отклоняет неположительное значение |
| `GainExperience(int amount)` | Накапливает опыт; отклоняет неположительное значение |
| `IsAlive()` | Возвращает `bool`: `true`, если `Health > 0` |
| `GetInfo()` | Возвращает строку с именем, здоровьем, уровнем и опытом, ничего не печатая |

### Проверка недопустимого урона

- После вызова `yaroslav.TakeDamage(-20);` здоровье Ярослава осталось прежним (75) — метод отклоняет неположительный урон через `return;`.
- Большой урон `artem.TakeDamage(200);` привёл здоровье Артёма к 0, а не к отрицательному значению — сработала проверка нижней границы.

## Собственный проект

**Тема проекта:** Каталог игр

**Главный класс:** `Game`

### Назначение объекта

Объект хранит все данные о каждой игре. Это избавляет от необходимости дублировать код для новых игр и позволяет быстро задавать их начальные параметры.

### Хранимые данные

1. Название игры
2. Жанр игры
3. Год выхода игры
4. Рейтинг игры

### Значения, задаваемые через конструктор

1. Название игры
2. Жанр игры
3. Год выхода игры

### Значения, задаваемые автоматически

1. Рейтинг игры

Рейтинг формируется автоматически: стартовое значение равно нулю, а дальнейшее изменение зависит от отзывов пользователей — исходя из их оценок.

### Действие `NewRating`

Добавляет рейтинг — параметр определяет, насколько повышается рейтинг. При добавлении проверяется, что введённый рейтинг больше 0.

При попытке добавить `5.5`, а затем `-5.5` рейтинг после обоих изменений остался равен `5.5` — проверка работает корректно.
