## Собственный проект

Тема проекта: Каталог игр

Главный класс: Game

Почему этот объект нужен программе: Он хранит все данные о каждой игре. Это избавляет от необходимости дублировать код для новых игр и позволяет быстро задавать их начальные параметры.


Какие данные хранит объект:

1. Название игры.

2. Жанр игры.

3. Год выхода игры.

4. Рейтинг игры.


Какие значения задаются через конструктор:

1. Название игры.

2. Жанр игры.

3. Год выхода игры.


Какие значения можно задавать автоматически:

1. Рейтинг игры

Рейтинг игр формируется автоматически: стартовое значение равно нулю, а дальнейшее изменение зависит от отзывов пользователей, исходя от их оценок.
