## Практическая работа №2

### Пять методов класса

Добавлены пять методов экземпляра, переносящие правила поведения внутрь объекта:

1. `TakeDamage(int damage)` — Уменьшает здоровье; отклоняет неположительный
   урон через ранний `return;`, Не опускает здоровье ниже нуля.
2. `Heal(int amount)` — Увеличивает здоровье, отклоняет неположительное
   значение.
3. `GainExperience(int amount)` — Накапливает опыт; отклоняет
   неположительное значение.
4. `IsAlive()` — Возвращает `bool`: `true`, если `Health > 0`.
5. `GetInfo()` — Возвращает строку с именем, здоровьем, уровнем и опытом,
   ничего не печатая.

### Проверка недопустимого урона

После `yaroslav.TakeDamage(-20);` здоровье Ярослава осталось прежним
(75), потому что метод отклоняет неположительный урон через `return;`.
Большой урон `artem.TakeDamage(200);` привёл здоровье Артёма к 0,
а не к отрицательному значению — сработала проверка нижней границы.

## Собственный проект

Тема проекта: Каталог игр

Главный класс: Game

Почему этот объект нужен программе: Он хранит все данные о каждой игре. Это избавляет от необходимости дублировать код для новых игр и позволяет быстро задавать их начальные параметры.


Какие данные хранит объект:

1. Название игры.

2. Жанр игры.

3. Год выхода игры.

4. Рейтинг игры.


Какие значения задаются через конструктор:

1. Название игры.

2. Жанр игры.

3. Год выхода игры.


Какие значения можно задавать автоматически:

1. Рейтинг игры

Рейтинг игр формируется автоматически: стартовое значение равно нулю, а дальнейшее изменение зависит от отзывов пользователей, исходя от их оценок.
